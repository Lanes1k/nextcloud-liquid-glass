# Liquid Glass для Nextcloud

CSS-тема в духе iOS: матовое стекло, цветной фон, тонкие блики, мягкие тени и скругления. Работает через [Custom CSS](https://github.com/nextcloud/theming_customcss), без модификации серверных файлов, JavaScript, внешних шрифтов или картинок.

**English version:** [README.md](README.md)

## Установка

1. Сначала скопируй существующий Custom CSS в отдельный файл, если он уже есть.
2. Установи и включи приложение **Custom CSS** (`theming_customcss`).
3. Открой **Настройки администратора → Оформление / Theming → Custom CSS**. Название раздела зависит от перевода и версии.
4. Вставь **всё содержимое `nextcloud-liquid-glass.css`**, без Markdown-ограждений, вместо прежнего CSS и сохрани.
5. Обнови страницу с очисткой кэша (`Ctrl+Shift+R`; на macOS — `Cmd+Shift+R`).

Изменения Custom CSS распространяются на всех пользователей этого сервера, не только на администратора. Установка и доступ к серверу в рамках этой работы не выполнялись.

## Что меняется

- Цветной сине-сиреневый фон с бирюзовым свечением.
- Тёмная стеклянная верхняя панель, полупрозрачное основное окно и навигация.
- Скруглённые меню, диалоги, вторичные кнопки и поля ввода.
- Подсветка навигации и строк файлов.
- Адаптация к светлому/тёмному режиму Nextcloud через его переменные, а не только к теме операционной системы.
- Более плотные поверхности на мобильных экранах; непрозрачный запасной вариант без `backdrop-filter`.
- Учёт reduced motion, reduced transparency, высокого контраста и forced colors.

Тема сознательно не меняет высоты строк, размеры навигации, расположение кнопок и порядок наложения окон. Не затрагивает страницу входа и публичные ссылки. Основные цветовые переменные Nextcloud сохраняются, чтобы редакторы документов и статусы ошибок не становились прозрачными.

## Настройка

Переменные находятся в первом блоке CSS:

```css
/* Меньше нагрузки на GPU */
--lg-blur: 12px;

/* Более прозрачное стекло (хуже читаемость на пёстром фоне) */
--lg-surface: rgba(var(--color-main-background-rgb, 255, 255, 255), .62);

/* Менее округлое окно */
--lg-radius: 18px;
```

Мобильный блок переопределяет размытие и радиус отдельно — при необходимости меняй и его.

Тема заменяет фон рабочего пространства. Чтобы оставить фон, выбранный в Nextcloud, удали из первого блока пять объявлений `background-color`, `background-image`, `background-repeat`, `background-size` и `background-attachment`.

## Совместимость и проверка

Ориентир для селекторов — исходники **Nextcloud 32 и Nextcloud Vue 8**; добавлены некоторые legacy ID и современные варианты классов. Это не означает проверенную совместимость со всеми версиями Nextcloud. В сторонних приложениях отдельные непрозрачные панели могут остаться в штатном виде.

`preview.html` — автономный интерактивный макет для оценки материала, со светлой/тёмной темой и мобильной навигацией. Он подключает тот же CSS-файл, но **не является работающим Nextcloud** и не заменяет проверку на твоём сервере. Открой его рядом с CSS-файлом в браузере.

Перед постоянным использованием проверь «Файлы», настройки, меню профиля, поиск, диалог создания/переименования, правую панель доступа и приложения, которыми пользуешься. Для точной подгонки нужны версия Nextcloud и скриншот проблемного экрана.

CSS воспроизводит прозрачность, размытие и блики. Настоящее динамическое оптическое преломление Liquid Glass, как в iOS, здесь не реализовано.

## Отключение и восстановление

Удали CSS из настроек и сохрани либо верни ранее сохранённый вариант.

Если интерфейс недоступен, администратор сервера может удалить **только настройку Custom CSS** через `occ`. Это также удалит любой другой CSS, находившийся в этом поле, поэтому сначала нужна резервная копия. Пример для обычной Linux-установки; путь, пользователь веб-сервера и команда для Docker могут отличаться:

```sh
sudo -u www-data php /var/www/nextcloud/occ config:app:delete theming_customcss customcss
```

Источник команды восстановления — README приложения Custom CSS.
